# AI Crypto Advisor

A personalized cryptocurrency dashboard that provides users with real-time market data, AI-generated insights, news, and entertainment content tailored to their investment preferences.

## Features

- **User Authentication** - Secure signup and login with JWT-based authentication
- **Personalized Onboarding** - Interactive quiz to capture user preferences (crypto assets, investor type, content interests)
- **Real-Time Coin Prices** - Live cryptocurrency prices from CoinGecko API
- **Market News** - Latest crypto news from CryptoPanic
- **AI Insights** - Personalized market analysis generated by OpenRouter AI
- **Crypto Memes** - Fun entertainment content for crypto enthusiasts
- **Voting System** - Like/dislike content to improve future recommendations

## Tech Stack

**Frontend:** React 19 + TypeScript + Vite  
**Backend:** Python 3.11 + FastAPI  
**Database:** PostgreSQL + SQLAlchemy  
**Authentication:** JWT (python-jose + bcrypt)  
**APIs:** CoinGecko, CryptoPanic, OpenRouter  
**Deployment:** Vercel (frontend), Railway (backend + database)

## Prerequisites

- **Node.js** 18+ and npm

## Setup Instructions

### 1. Clone the Repository

```bash
git clone <repository-url>
cd cryptoAdvisor
```

### 2. Backend Setup

```bash
cd backend

# Create virtual environment
python -m venv venv

# Activate virtual environment
# Windows:
venv\Scripts\activate
# Mac/Linux:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Create .env file
cp env.example .env
```

Edit `.env` and configure:
```env
DATABASE_URL=postgresql://user:password@localhost:5432/crypto_advisor
SECRET_KEY=your-secret-key-here
CRYPTOPANIC_API_KEY=your-cryptopanic-key
OPENROUTER_API_KEY=your-openrouter-key
```

```bash
# Run database migrations
alembic upgrade head

# Start backend server
uvicorn app.main:app --reload
```

Backend will run at `http://localhost:8000`

### 3. Frontend Setup

```bash
cd frontend

# Install dependencies
npm install

# Create .env file
cp env.example .env
```

Edit `.env` and configure:
```env
VITE_API_URL=http://localhost:8000
```

```bash
# Start development server
npm run dev
```

Frontend will run at `http://localhost:5173`

## Available Scripts

**Backend:**
- `uvicorn app.main:app --reload` - Start development server
- `alembic upgrade head` - Run database migrations
- `alembic revision --autogenerate -m "message"` - Create new migration

**Frontend:**
- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint

## Deployment

**Frontend (Vercel):**
1. Connect GitHub repository to Vercel
2. Set environment variable: `VITE_API_URL=<railway-backend-url>`
3. Deploy automatically on push to main branch

**Backend (Railway):**
1. Create new Railway project
2. Add PostgreSQL database
3. Deploy backend service from GitHub
4. Set environment variables in Railway dashboard
